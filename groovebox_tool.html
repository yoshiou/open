🎛 GROOVE BOX ツール

Chrome / Edge で開き、GROOVE BOX をUSBでつないでください(PCでもAndroidでも可)。機器の電源が入ってメニューが出ている状態で使います。
未接続
接続のヒント (Android / つながらないとき)通常は左のボタン(Web Serial)。Androidで機器が候補に出ない/つながらない場合は右のボタン(WebUSB)を使います。Androidは、スマホ側の端子が1つなので、MIDIコントローラーも使うときはUSBハブ(OTG対応)が必要です。ページは https:// で開いてください(file:// や content:// だと機能が無効になることがあります)。
画面の鍵盤とパッド
使い方機器でGROOVE BOXを開いた状態で、画面をタッチして演奏します(複数指OK)。鍵盤=PLAYのPKEY音色(SMP KEYSモードならサンプル鍵盤)、パッド=ドラム8レーン(ch10)。機器がREC中なら演奏が曲に記録されます。ブラウザの許可は不要です。強弱は鍵/パッドを押した位置の高さ(上=弱い、下=強い)。画面を横向きにすると鍵盤が大きくなります。

C3 – C5
全曲バックアップ / 復元 (ユーザー保存の8枠)

復元すると、機器の保存枠はすべて上書きされます。
現在の曲 (GROOVE BOXで編集中の曲)
WAV書き出し (録音)
機器で GROOVE BOX を開き、書き出したい曲を読み込んだ状態で押します。曲を頭から実時間で再生しながら録音します(機器のスピーカーからも音が出ます)。ミュート/ソロもそのまま反映されるので、トラック単位の書き出しもできます。

MIDIコントローラーで演奏
PCにつないだUSB MIDIコントローラーの演奏を、機器へ転送して鳴らします(機器はGROOVE BOXを開いておく)。ch1-9,11-16=鍵盤(PLAYのPKEY音色 / SMP KEYSモードならサンプル鍵盤) / ch10=ドラム(GM配置: 36=KICK 38=SNARE 42=HAT 46=OPEN HAT 41-50=TOM 39=CLAP 49/51=CRASH)。REC中なら演奏が曲に記録されます。ドラムレーンにサンプルを割り当てていればサンプルが鳴ります。ブラウザはChrome/Edge。
